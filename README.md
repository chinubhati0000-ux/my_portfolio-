- Responsive layout with automatic light and dark mode

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/chinubhati0000-ux/portfolio.git
   ```
2. Open `index.html` in your browser.

## Deploy

1. Push `index.html` to a GitHub repository.
2. Import the repository at [vercel.com](https://vercel.com) and click **Deploy**.

## Customize

- **Colors:** edit the variables at the top of the `<style>` block in `index.html`.
- **Projects:** copy any `<article class="card">` block in the "More from GitHub" section and change the text and link.
- **Contact details:** update the footer at the bottom of the file.
